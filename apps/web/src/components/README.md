# `components/`

Presentational components for the web application.

| Directory | Purpose                                         |
| --------- | ----------------------------------------------- |
| `ui/`     | Reusable, non-layout primitives                 |
| `layout/` | Structural pieces (shells, headers, navigation) |

**Status:** architectural boundary only — no components exist yet.

Components are added together with the phase that needs them. There is no
Button system, Input system, Modal system, data table, dashboard card, status
badge or form framework here: those belong to the dedicated UI/UX design-system
phase and to the business modules.
