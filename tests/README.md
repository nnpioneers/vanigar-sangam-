# tests/

Cross-application end-to-end tests live here.

Unit and integration tests live next to what they cover:

- `apps/api/tests/` — API and service tests
- `apps/web/tests/` — web component tests
- `packages/rules/tests/` — pure business-rule tests

No test framework is installed in Phase 1.1; it is added together with the
first test in a later phase.
